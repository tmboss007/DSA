# 921. Minimum Add to Make Parentheses Valid

**LeetCode Problem:** [Minimum Add to Make Parentheses Valid](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/)  
**Difficulty:** Medium  
**Topic:** Stack / Greedy  
**Language:** Python 3

---

## 📌 Problem

You are given a string `s` containing only `(` and `)`.

In one move, you can insert either `(` or `)` at any position.

Return the **minimum number of insertions** required to make the string valid.

### Examples

```text
Input: s = "())"
Output: 1
