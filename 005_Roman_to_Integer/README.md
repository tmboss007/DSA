## Problem Statement

Roman numerals are represented by seven different symbols:

| Symbol | Value |
|:------:|------:|
| `I` | 1 |
| `V` | 5 |
| `X` | 10 |
| `L` | 50 |
| `C` | 100 |
| `D` | 500 |
| `M` | 1000 |

Given a string `s` representing a Roman numeral, convert it into an integer.

**Example 1:**

```text
Input:  s = "III"
Output: 3
